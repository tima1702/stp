# Теоретическая часть

# 1. Введение в большие языковые модели (LLM)

**Большая языковая модель (Large Language Model, LLM)** — это тип искусственного интеллекта, обученный на огромных объёмах текстовых данных для понимания и генерации человеческого языка. LLM основаны на архитектуре трансформеров и способны выполнять широкий спектр языковых задач.

### Основные характеристики LLM:

- **Параметры**: количество обучаемых весов в модели (от миллионов до триллионов)
- **Контекстное окно**: максимальное количество токенов, которое модель может обработать за один раз
- **Токенизация**: процесс разбиения текста на минимальные единицы обработки
- **Инференс**: процесс генерации ответа моделью на основе входного запроса

## 2. Локальные vs облачные LLM

### Преимущества локальных LLM:

- **Приватность данных**: весь код и запросы остаются на вашем компьютере
- **Независимость**: работа без интернета и ограничений API
- **Кастомизация**: возможность тонкой настройки под конкретные задачи
- **Экономия**: отсутствие платы за API-запросы

### Недостатки локальных LLM:

- **Требования к ресурсам**: необходимость в мощном железе
- **Размер моделей**: занимают значительное дисковое пространство
- **Качество**: меньшие модели могут уступать в качестве крупным облачным

## 3. Что такое Ollama?

**Ollama** — это инструмент для запуска больших языковых моделей локально. Он упрощает процесс установки, управления и использования LLM на персональном компьютере.

### Ключевые особенности Ollama:

- **Простота установки**: одна команда для загрузки и запуска модели
- **Управление моделями**: удобные команды для скачивания, удаления и переключения между моделями
- **API-интерфейс**: REST API для интеграции с другими приложениями
- **Кроссплатформенность**: поддержка Windows, macOS и Linux
- **Оптимизация**: автоматическая оптимизация для различных типов железа

## 4. Форматы моделей и квантизация

### GGUF (GPT-Generated Unified Format)

GGUF — современный формат для хранения LLM, оптимизированный для инференса. Основные преимущества:

- Эффективное использование памяти
- Быстрая загрузка моделей
- Поддержка различных типов данных

### Квантизация

**Квантизация** — процесс уменьшения точности представления весов модели для экономии памяти и ускорения работы.

Типы квантизации в Ollama:

- **Q4_0**: 4-битная квантизация, баланс размера и качества
- **Q4_K_M**: улучшенная 4-битная квантизация с лучшим качеством
- **Q8_0**: 8-битная квантизация, минимальная потеря качества
- **FP16**: 16-битная точность, высокое качество, больший размер

## 5. Специализированные модели для программирования

### Code Llama

- Основана на Llama 2, специально дообучена на коде
- Поддерживает множество языков программирования
- Размеры: 7B, 13B, 34B параметров

### DeepSeek Coder

- Модель от DeepSeek, оптимизированная для кодинга
- Высокое качество генерации кода
- Эффективная работа на ограниченных ресурсах

### StarCoder2

- Разработана Hugging Face и BigCode
- Обучена на данных The Stack v2
- Поддержка 600+ языков программирования

### Qwen2.5-Coder

- Последняя версия серии Qwen для программирования
- Улучшенное понимание контекста
- Поддержка сложных алгоритмических задач

## 6. Аппаратные требования

### CPU vs GPU

- **CPU**: универсальный процессор, медленнее для LLM
- **GPU**: специализированные вычисления, значительно быстрее
- **VRAM**: видеопамять для хранения модели (критично для больших моделей)

### Расчёт требований к памяти

Приблизительная формула: **Размер модели = Количество параметров × Биты на параметр ÷ 8**

Пример для модели 7B с квантизацией Q4:

- 7 миллиардов параметров × 4 бита ÷ 8 = ~3.5 ГБ

## 7. Промпт-инжиниринг для кода

### Эффективные стратегии:

1. **Конкретность**: точно описывайте что нужно получить
2. **Контекст**: указывайте язык программирования и версию
3. **Примеры**: приводите образцы входных/выходных данных
4. **Структура**: разбивайте сложные задачи на подзадачи

### Пример хорошего промпта:

```
Напиши функцию на Python 3.9+, которая:
1. Принимает список чисел
2. Возвращает список только простых чисел
3. Включи docstring и обработку ошибок
4. Добавь пример использования
```

# Задачи для выполнения

## 1. Установка Ollama

- Перейдите на официальный сайт [https://ollama.com/](https://ollama.com/) и скачайте установщик для вашей ОС.
- Установите Ollama, следуя инструкциям на сайте.
- В терминале выполните команду:

```
ollama --version
```

- чтобы убедиться, что установка прошла успешно.

## 2. Загрузка и запуск модели

- Выберите лёгкую модель для кодинга, например:

```
ollama pull deepseek-coder:1.3b
```

- Запустите её в интерактивном режиме:

```
ollama run deepseek-coder:1.3b
```

- Задайте модели вопрос, например: _“Напиши на Python функцию, которая проверяет, является ли число простым”._

## 3. Работа с командами Ollama

- Изучите команды:
```
ollama list
ollama run
ollama pull
ollama rm
```

## 4. Сохранение результата (практика на разных задачах)

Выберите и выполните **минимум шесть** задач с помощью модели. Сохраните ответы модели в файлы и проверьте их работоспособность.

**Примеры заданий:**

1. HTML + CSS
    
    _“Сделай HTML-страницу с кнопкой, которая меняет цвет при наведении”_, сохранить как button.html.
    
2. Python
    
    _“Напиши скрипт, который выводит таблицу умножения до 10”_, сохранить как table.py.
    
3. JavaScript
    
    _“Создай HTML-страницу с кнопкой, при нажатии на которую появляется случайное число”_, сохранить как random.html.
    
4. Markdown
    
    _“Сделай README.md для приложения заметок на React”_, сохранить как README.md.
    
5. SQL
    
    _“Напиши SQL-запрос для выборки всех студентов старше 20 лет из таблицы students”_, сохранить как query.sql.
    

  

Для сохранения использовать перенаправление вывода:

```
ollama run deepseek-coder:1.3b "ВАШ ЗАПРОС" > файл
```
